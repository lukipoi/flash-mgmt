# 2026-11-01 工作日志

## flash-mgmt GUI 升级：Endfield 风格框架接入（续）

### 已完成
- **StatCard.vue 改造成 Endfield 母题范本**：去掉旧 `color` 映射（原 `cyan/purple/amber/blue`
  中 purple/amber 根本不在 colorMap、且硬编码 `ring-cyan-500/20`），改为 `tone` 系统映射到
  Endfield 角色色（action/data/region/gain/notice/special/alert），卡片用 `corner-brackets`
  （`--bracket-color: var(--ef-action)`）+ `bg-surface-raised`/`ring-line`，hover 微抬升。
  注意 `corner-brackets` 伪元素向外侧伸出，父级必须 `relative` 且不能 `overflow-hidden`。
- **pages/index.vue**：7 个 StatCard 的 `color=` 全部改为 `tone=`（action/data/gain/region/
  notice/data/special），无残留 cyan/purple/amber/blue。
- **多主题框架完整化**（用户原话"你来搭建多主题这个框架"）：
  - 新增 `composables/useTheme.ts`：dark/light 单一来源，`useState` 存 'flash-theme'，
    onMounted 对齐 localStorage，提供 setTheme/toggleTheme。
  - `nuxt.config.ts`：`ui.colorMode:false`（关掉 @nuxt/ui 自带的 @nuxtjs/color-mode，
    否则它会用自己 localStorage key 在刷新后覆盖我的主题选择，导致亮色回退暗色）；
    `app.head.script` 加防闪烁 inline 脚本（首屏绘制前按 localStorage 设 data-theme+class）。
  - `layouts/default.vue`：去掉内联主题逻辑，改用 `useTheme()`。
- **验证**：`npx nuxt typecheck` 我改的文件零错误（唯一命中是 pre-existing 的
  `pages/index.vue(37) Cannot find name 'UBadge'`，render function 里 h(UBadge) 的自动导入
  类型问题，非本次引入）；dev server 返回 200，SSR HTML 含 data-theme/class=dark/防闪烁脚本/
  corner-brackets/hatch/全部 7 个 StatCard tone 类。
- **抓到并修掉一个真 bug**：`useTheme.ts` 最初把 `useState` 写在模块顶层，Nuxt 报
  "composable called outside setup"，已移入 `useTheme()` 函数内。
