这是USB接口芯片CH372和CH375的简化版驱动程序及动态链接库的源程序包

最小开发环境：
	WINDOWS 98 或更高版本操作系统
	VC 5.0 或更高版本编译器
	WIN98 DDK 或更高版本驱动开发包，由微软免费提供

文件目录说明：
	WDM 驱动程序源程序
	DLL 动态链接库源程序
	EXE 演示和测试用的例子应用程序源程序
	MCU 演示和测试用的例子单片机端源程序，以MCS51单片机为例
	ISSUE 由上述源程序产生的正式发行版目标程序
		默认是采用环保的INF安装信息的驱动安装方法，
		如果需要可执行安装工具SETUP.EXE可到沁恒网站免费下载

说明：
1、所有驱动/动态库/应用程序均同时支持WINDOWS 98/ME/2000/XP操作系统
2、默认是同步I/O操作，如果需要效率更高的异步I/O操作可以修改DLL及应用程序
3、仅供了解和学习USB设备的驱动程序及动态库的开发过程，不建议用于商用目的
4、绝大多数人只需要会使用驱动实现功能就行，没有必要每人都自己会开发驱动
5、虽然有中文注释，但是修改该驱动程序仍然需要具有一定的技术功底，包括：
	精通C语言，并了解：操作系统结构、WIN32的API、DDK、编译工具等，
	如果不具备上述条件，那么也可以看看参考以了解USB通讯过程，
	一般情况下，沁恒电子不提供针对驱动程序开发的技术支持，
	技术支持: tech@wch.cn, tech@winchiphead.com
6、稍加修改完全可以用于其它USB芯片, 不过作者希望你是用于CH372和CH375芯片
