DESIGN LANGUAGE / ENFIELD · 装备清单

工业控制台，
不是消费级后台。

这份方案不发明新风格。它把 flash-mgmt 已经在用的 endfield-ui 令牌——信号黄、直角切角、1px 描边、等宽数据、零偏移阴影——提炼成一套明确的规则，并给动效划好边界。

单一行动色 硬边 / 切角 数据优先 标注感 动效只做状态可读
一句话总纲：界面像一张可核对的装备清单，所有视觉重量让给「型号、数量、状态」；黄色只表示「可点 / 选中 / 进行中」，不表示好看。动效只在人需要知道系统在干嘛的瞬间出现，其余全静。

01

设计原则

五条硬规则，用来判断任何新组件 / 新动效该不该做。有冲突时，序号小的优先。

P1

黄色是信号，不是装饰

#fffa00 全站只用于主行动、当前选中、进行中指示。禁止拿它做背景块、渐变、大标题、装饰条。明暗主题下它同值，是唯一不随主题变化的锚点。

P2

硬边优先，圆角克制

默认直角；圆角只有 2 / 4 / 6px 三档，且只给小控件。卡片、表格、弹窗一律靠 1px 描边分层，不靠投影堆叠。

P3

母题有配额

切角、斜纹、角括号、警示条纹是「标注语言」，每屏最多出现 1–2 处，用在页头、强调卡、危险区。列表和表格里一律不用。

P4

数据用等宽

型号、编号、数量、十六进制、日期、ID 一律 mono + tabular-nums，保证逐行对齐。正文用无衬线，标题可用 display，但字重不夸张。

P5

动效服务可读性

只回答三件事：在忙吗 / 成功了吗 / 变的是哪一项。不回答这三件的动效，一律不做。状态变化只改颜色、透明度、描边，不改尺寸与位置。

P0

先对齐现有令牌

任何新样式必须先从 theme.css 里找现成变量。找不到再提案新增，不许就地写十六进制硬编码——这是风格漂移的头号来源。

07

禁止清单

下面这些加进去，风格立刻崩。左边是反面示例，鼠标移过去就能体会为什么难受。

反面示例 · 别这么做

位移 + 旋转 + 缩放 + 悬浮投影，还带 300ms 缓动——按钮「乱飞」的标准形态。这个按钮只存在于本框内。

明确禁止

✕按钮 hover 位移 / 缩放 / 旋转 / 涟漪 / 悬浮投影
例外 → 折叠箭头的 rotate(90deg) 是状态过渡（修订 3）；选中框平移（录入页 / 侧栏）是第 4 个特批例外，但只放行框这一层，按钮与菜单项本体仍然禁止位移（修订 5）
✕列表卡片逐个错峰入场（stagger）——库存表天天点，第三次就烦
✕路由整页淡入淡出、页面切换滑动
✕StatCard 数字滚动计数
✕装饰性循环：呼吸、浮动、闪烁、边框流光、3D 封装自动旋转

常驻循环的唯一例外 · hazard 警示条滚动

工业设备上「危险 / 运行中」的标准语言，上方红框已启用（0.8s / 周期）。仅此一条允许常驻循环，其余装饰性循环仍然禁止。

项约束
位置 / 配额仅危险操作区、不可撤销确认、设备运行中；每屏最多 1 处
速度0.8–1.2s / 周期，硬下限 0.45s；不加发光、不双层叠加
色彩只用现有 danger / action / warning，不引入新色
无障碍prefers-reduced-motion 下立即静止，保留静态条纹
→ 打开专项演示（配色 / 速度 / 条高可现场调）
验收口径：把动效全部关掉，界面信息仍然完整、操作仍然能走通，就说明动效没越界。反过来，如果关掉动效后某个操作「不知道成没成」，那才是该补动效的地方。
