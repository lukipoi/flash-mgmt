ONE FRAME, MOVING DOWN THE SIDEBAR

同一个框，换成沿侧栏上下滑。

左边是 layouts/default.vue 里那 12 项竖排导航，现在的选中态是统一信号黄（淡黄底 + 黄字 + 左侧 4px 竖条 before:marker-bar）。这套语言搬过来我按「一个框在菜单项之间平移」理解 —— 沿 Y 轴滑，左侧竖条跟着框一起走。

⚠️ 三处跟录入页不一样，都做成了可选项，别直接照抄 S1：
① 方向：竖排 → translateY，框用实测的 top / height 定位，12 项等高所以不用动宽度。
② 换色：菜单项没有语义色，全体统一信号黄是「信号黄唯一行动色」这条规范的结果。给 12 项各配一色会很花也破规范 —— 所以我只做了按 3 个功能组换色（仪表盘中性 / 各类列表数据蓝 / 各类录入专用紫）当对照，默认仍是统一信号黄。20:21 用户已拍板 「不用换色」，项目落地就是统一信号黄；分组换色只留在本页作对照，没有引入任何新颜色。
③ 长距离：从「仪表盘」跳到「录入电路板」要跨 11 格，260ms 里框飞过整条侧栏，很可能晃眼、拖慢导航。工具条给了「固定 / 距离自适应 / 远距离直接落定」三种策略，务必点「跳到末项」试一次。项目落地暂按样板默认「固定 260ms」，跨 11 格若晃眼再单独加保护，不影响 N1 本身。

20:21 已拍板 N1 + 不换色，已落地到项目代码。布局文件是跨页常驻 DOM，框不会随页面卸载，落地比录入页简单。

02

四个侧栏样板 · N1 已落地

20:21 已拍板 N1，项目里落地的就是它；N2–N4 留作备选与对照。点「试用」会切到该方案并自动演示一次「仪表盘 → 芯片列表」；之后直接点舞台左侧菜单反复看。四个方案里菜单项本体都不动，区别在框怎么滑、左侧竖条跟不跟着、颜色换不换。

N1纵向整框平移已落地
框 + 竖条一起 260ms · 统一信号黄 · translateY
怎么动：录入页 S1 的纵向版。底色框和左侧 4px 竖条作为一个整体滑到新菜单项，完全保留现在的选中态视觉，只是从「各自点亮」变成「一个实体在移动」。不引入新颜色，不破规范，落地量最小。
N2竖条先行，底色随后
竖条 120ms 先到 → 底色框 200ms@80ms
怎么动：左侧黄色竖条先快速滑到位，淡黄底色框稍后跟上。呼应你在危险弹窗挑的 F1 生长线，最有「去哪儿了」的交代感；代价是两段时序，快速连点时要先清掉未播完的延迟，且 N1 的一体感会弱一点。
N3按功能组换色未采用
N1 + 三组语义色 · 蓝 / 紫 / 中性
怎么动：滑法同 N1，但框色随目标分组变：仪表盘中性、7 个「列表」页数据蓝、4 个「录入」页专用紫。这是「颜色改变」在侧栏里唯一讲得通的形态——12 项各一色会花掉。⚠️ 但它等于让侧栏出现非行动色，跟「信号黄唯一行动色」冲突，20:21 用户已明确「不用换色」，此方案未采用；工具条的配色下拉只作对照，项目里没有启用。
N4只滑竖条（最轻）长距离安全
底色瞬时落定 · 仅竖条 220ms 滑动
怎么动：底色框直接在新位置出现，只有那条 4px 黄色竖条滑过去。最克制、最不晃，跨 11 格也不会有一条大色块飞过整栏；如果你觉得 N1 长距离太闹，这版是保底。缺点是一体感最弱，更像「指示线移动」而不是「框移动」。
✕仍然不做
菜单项位移 · spring 回弹 · 右侧内容动效 · stagger
框可以滑，菜单项不可以。12 个链接连同文字、图标必须钉在原位；不做弹性回弹、不做逐项错峰点亮、不做装饰性循环。右侧主内容区保持瞬时路由切换、零动效；「扫码查详情」按钮不参与选中框。
03

N1 · 已落地实现记录

已改两个文件：layouts/default.vue（nav + 定位 JS）与 assets/css/endfield/utilities.css（.nav-frame / .nav-bar 一套）。统一信号黄、不换色，没有按菜单项 / 功能组分色。原 nav 是 space-y-1 的 block 布局，落地时改成 flex flex-col gap-1 并给菜单项加 shrink-0 —— space-y-1 会给所有子元素（含绝对定位的框）加 margin-top:4px，框会多偏 4px。12 项仍由 navItems v-for 生成、isActive() 精确匹配 route.path，NuxtLink 的 active-class / exact-active-class 保持关闭。布局是跨页常驻 DOM，框只建一次。

/* default.vue · 用 route.path 定位，别用 click */
function placeNavFrame(instant = false) {
  const nav = sideNav.value;
  if (!nav) return;
  const item = nav.querySelector(`[data-to="${route.path}"]`);
  for (const el of [navFrame.value, navBar.value]) el?.classList.toggle('is-hidden', !item);
  if (!item) return;                  /* 详情页：原本就无高亮，框不悬空 */
  const r = item.getBoundingClientRect(), n = nav.getBoundingClientRect();
  for (const el of [navFrame.value, navBar.value]) {
    if (!el) continue;
    if (instant) el.classList.add('no-trans');
    el.style.setProperty('--fy', `${r.top - n.top}px`);
    el.style.setProperty('--fh', `${r.height}px`);
  }
  if (instant) { void navFrame.value?.offsetWidth;
    navFrame.value?.classList.remove('no-trans');
    navBar.value?.classList.remove('no-trans'); }
}
watch(() => route.path, () => nextTick(() => placeNavFrame()));
onMounted(() => {
  nextTick(() => placeNavFrame(true));
  navObserver = new ResizeObserver(() => placeNavFrame(true));
  if (sideNav.value) navObserver.observe(sideNav.value);
});
onUnmounted(() => navObserver?.disconnect());
样板落地要点
N1 · 已落地把每个链接上的 bg-action/10 / ring-1 ring-action/20 / before:marker-bar 全部搬到 .nav-frame + .nav-bar，链接只留文字色；两层用同一组 --fy / --fh；颜色写死 var(--ef-action)，没有颜色过渡
N2竖条 transition-duration:120ms，底色框 200ms + delay:80ms；快速连点先清掉 delay 未播完的状态
N3 · 未采用用户明确「不用换色」，所以 navItems 没有加 group 字段，CSS 也没有分组色；本页的分组换色下拉仅作对照
N4 · 备选底色框加 .no-trans 瞬时落定，只有竖条带过渡；跨格多时最稳。若长距离滑动验收觉得晃，可单独挂这个保护，不必换掉 N1
七个坑：① before: 竖条必须删掉，否则它会留在旧菜单项上、跟新框同时出现两条；② 两层都 pointer-events:none，文字层 z-index:4 压过框的 2 / 竖条的 3；③ 位置用 getBoundingClientRect() 相对 nav 实测，space-y-1 的 4px 间隙会被框跨过；④ 用 watch(() => route.path) 而不是 click 事件——浏览器前进/后退、别的页面里 navigateTo 跳转也要让框跟上；⑤ 位移走 transition 而非 animation + forwards，快速连点天然可打断；初始化与 ResizeObserver 重算时临时关过渡，否则侧栏高度变化框会「自己滑一下」；⑥ 若以后给 nav 加 overflow-y:auto，滚动时也要重算位置。prefers-reduced-motion 由 theme.css 全局兜底；⑦ 落地时把 space-y-1 换成 flex flex-col gap-1 + shrink-0：space-y-1 会给 nav 的所有子元素（含绝对定位的框）加 margin-top:4px，框会多偏 4px；shrink-0 防止 12 项在小屏被 flex 压缩。
验收口径：只有框在移动，12 个菜单项连同图标文字零位移 / 零缩放 / 零旋转；右侧内容瞬时切换；浏览器前进/后退框也能跟到正确项；跨 11 格时不晃眼（按你挑的策略）；快速连点不留残影；明暗两套主题下框与竖条都有对比度；prefers-reduced-motion 直接落定。
