EXPAND / COLLAPSE · TWO-LEVEL CATEGORY TREE

展开要有来路，收起要有回路。

芯片类型页点开二级分类原本是 v-if 硬切，一按就整块蹦出来。G1 已落地：只动高度、透明度和一条 1px 引导线，子项整体一起出现，绝不逐条错峰；收起按原路逆向，所以全用双向 transition。折叠箭头也跟着转 90°——同一个 chevron 旋转，不再硬换字形。

G1 已落到项目代码。pages/chip-types/index.vue 的 v-if 换成常驻 DOM + is-open，样式在 assets/css/endfield/utilities.css，规范页 06 章已同步。下面舞台仍可切 G2–G5 对比，挑中别的再说一声。仍然禁止：子项错峰入场、上浮位移、内容缩放变形、spring 回弹、箭头以外的装饰性旋转。

舞台用的是真实分类数据；右侧操作按钮仅作版式示意，点整行都会展开。

02

五个候选

G1 是项目当前方案，其余四个留作对照。点「试用」会切到该方案并自动展开第一项；也可以直接点任意一级分类，反复体会展开 / 收起与箭头旋转。五个方案共用同一套箭头旋转——那是状态过渡，不随方案变化。

G1引导线生长 + 整体淡入已落地
高度 240ms · 引导线 220ms · 子项 180ms@60ms · 箭头旋转 220ms · 总约 300ms
怎么动：容器从上撑开的同时，左侧 pl-11 空区里一条 1px 竖线自顶端长到底；子项作为一整块淡入（不是一条一条来）；折叠箭头由 ▸ 转到 ▾，220ms 同步跟上。呼应危险弹窗「点 → 线」的生长语言，但收得更轻。收起时箭头转回、线缩回、子项先淡出、高度最后收回。
G2纯高度撑开
高度 220ms · 无附加 · 总 220ms
怎么动：只有 grid-template-rows: 0fr → 1fr，内容被容器边缘自然揭示，不加任何淡入或线条。最贴常规 200ms 规范，最像「原生就该有的细节」，存在感也最低。
G3撑开 + 横向擦除
高度 160ms · 擦除 260ms@40ms · 总约 300ms
怎么动：位置先落下（高度快），内容再用 clip-path 从左往右擦出来（慢一点）。和弹窗 F1 的「线长成窗」同源，但方向横过来。拉开层级感，比 G1 更「仪器读数刷出来」。
G4状态线先行
黄线 180ms → 高度 220ms@140ms · 总约 360ms
怎么动：先在一级行底部亮起一条 --ef-action 1px 信号黄线，从左扫到右；线扫满，二级内容才落下。信号黄在这里是「正在展开」的进行中信号，不装饰。收起时容器先收、黄线最后缩回，最贴工业控制台的因果顺序。
G5G1 慢速版
高度 400ms · 线 360ms · 子项 240ms@120ms · 总约 520ms
怎么动：动作与 G1 完全一样，只是整体拉慢到能看清每一段。适合拿来做评审，不适合天天点——分类树是高频操作，超过 400ms 就会觉得粘手。
✕仍然不做
stagger / translateY / scale / spring / 装饰性旋转
二级分类一屏能有好几组，逐条错峰会像「刷榜」，正是你说的乱飞；子项上浮会把文字拖虚。箭头旋转是唯一放行的旋转：它是「展开 / 收起」的状态过渡，只转这一个 20px 图标、双向同一条曲线，不带动整行或内容。3D 封装自动旋转、按钮 hover 旋转仍一律禁止。
03

G1 落地清单

已按下面结构落到项目里。核心是把 v-if 换成常驻 DOM + 状态类；高度用 CSS Grid 的 0fr / 1fr，不需要 JS 去量 auto 高度，也不用给容器拍一个不精确的 max-height。

<!-- index.vue：is-open 挂在一级卡片上，箭头与二级区共用同一状态 -->
<div class="ct-card ..." :class="{ 'is-open': isExpanded(root) }">
  <button class="ct-caret-icon" :aria-expanded="isExpanded(root)">
    <UIcon name="i-lucide-chevron-right" />   // 单个图标，靠 CSS 旋转 90°
  </button>
  …
  <div class="ct-children" :aria-hidden="!isExpanded(root)"
       :inert="!isExpanded(root) || undefined">   // 别写 false：inert 存在即生效
    <div class="ct-children-inner">
      <span class="ct-guide" aria-hidden="true"></span>
      <div class="ct-pad">
        <div v-for="child in childrenFor(root)" :key="child.id">…</div>
        <p v-if="!childrenFor(root).length">暂无二级分类…</p>
      </div>
    </div>
  </div>
</div>

/* utilities.css · G1 关键几条 */
.ct-children             { display:grid; grid-template-rows:0fr;
                           transition:grid-template-rows 240ms var(--ease-exit); }
.ct-card.is-open > .ct-children { grid-template-rows:1fr; }
.ct-children-inner       { min-height:0; overflow:hidden; position:relative; }
.ct-pad                  { border-top:1px solid var(--ef-line); padding:4px 0;
                           opacity:0; transition:opacity 160ms ease; }
.ct-card.is-open .ct-pad { opacity:1; transition:opacity 180ms ease 60ms; }
.ct-guide                { transform:scaleY(0); transition:transform 220ms var(--ease-exit); }
.ct-card.is-open .ct-guide { transform:scaleY(1); }
.ct-caret-icon           { transition:transform 220ms var(--ease-exit); }
.ct-card.is-open .ct-caret-icon { transform:rotate(90deg); }
样板在共用骨架上追加什么
G1已落地。.ct-guide 的 scaleY(0→1) 220ms + .ct-pad opacity 0→1 180ms@60ms + .ct-caret-icon 的 rotate(0→90deg) 220ms；全部写成双向 transition
G2什么都不加，只留共用的高度过渡
G3高度缩到 160ms；.ct-children-inner 加 clip-path: inset(0 100% 0 0) → inset(0 0 0 0) 260ms@40ms
G4一级行底部加一条 1px --ef-action 线，scaleX(0→1) 180ms；展开时高度加 140ms 延迟，收起时不加
G5G1 的三段时长整体放大到 400 / 360 / 240ms@120ms
五个落地坑，先记下：
① border-t 必须挪进 .ct-children-inner（现在是 .ct-pad），否则 0fr 时那条分隔线还留着，折叠态看着像没展开干净；
② 一级卡片外层本来就有 overflow-hidden，别再叠一层；
③ 搜索时 isExpanded() 恒为 true，所有命中的一级会同时展开——同时，不要错峰，否则一输入关键字整页乱闪；
④ grid-template-rows 过渡需要 Chrome 107+ / Safari 16+，旧浏览器会直接硬切（等于回到现状，不会坏）。prefers-reduced-motion 下全部直接切换；
⑤ 常驻 DOM 后折叠态的二级按钮仍在文档里，必须加 :inert + :aria-hidden，否则键盘能 Tab 进看不见的「编辑 / 删除」。inert 要写 !isExpanded(root) || undefined——部分 Vue 版本会把 :inert="false" 渲染成 inert="false"，而这个布尔属性「存在即生效」，会把展开态按钮一起废掉。箭头则用单个 chevron + rotate，换字形是没法做旋转过渡的。
验收口径：关掉动效后，分类树仍要能完整展开 / 收起，箭头方向仍要正确（旋转是过渡，不是方向的唯一来源），子项文字不被裁切、计数不重叠、搜索命中的一级全部可见。动效只负责「这一块是刚从上面长出来的」，不负责表达层级——层级靠缩进和 corner-down-right 图标。
