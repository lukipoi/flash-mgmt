ONE ALLOWED LOOP / 唯一被允许的常驻循环

会流动的警示带。

原型是你截图里那个红框：1px 红边、顶部 -45° 斜纹。现在让斜纹连续横移——工业设备上「危险 / 运行中」的标准语言，不是装饰流光。下面所有参数都能现场调，挑完直接定稿。

但它是例外，不是开口子。规范 07 章原本禁止一切装饰性循环。这里为 hazard 单开一条例外，带配额、限速和无障碍约束，防止它蔓延到普通卡片和页头。约束写在最后一章。

03

反面：调过头就难受

同一个组件，只把速度拉到 0.22s 再加一层发光。看一眼就知道为什么要限速。

危险操作

0.22s/周期 + 红色发光 · 晃眼、抢内容、像报警灯

✕周期短于 0.45s（视觉上变成闪烁，不是流动）
✕给条纹加发光 / 渐变高光 / 双层叠加
✕同一屏出现两条同时滚动的警示条
✕把滚动条用到普通卡片、页头、按钮、列表行
04

例外条款（写进规范）

这是对 规范 07 章 P5 / 禁止清单的唯一修订，其余条款不变。

项约束
允许位置仅危险操作区、不可撤销确认、设备运行中指示
配额每屏最多 1 处；不与母题配额中的其他项叠加
速度0.8–1.2s / 周期（约 19–28 px/s）；硬下限 0.45s
色彩只用现有 --ef-danger / --ef-action / --ef-warning，不加新色、不加发光
循环仅此一条允许常驻循环；等待指示器（扫光 / 骨架脉冲）仍按原规范，等待结束即移除
无障碍prefers-reduced-motion: reduce 下 立即静止，保留静态条纹
共存框内按钮仍只改背景色，禁止位移 / 缩放 / 旋转
验收口径不变：把动效全关掉，警戒框仍然一眼看出是危险区（靠红边 + 红标题 + 文案），条纹只是加强。如果关掉滚动后就不像危险区了，说明设计有问题。
