v2 / POINT → LINE → WINDOW

点拉成线，线长成窗。

上一轮的「遮罩淡入」被否了——跟没加一样。这轮按你说的做两段式形状生长：中心一个点横向拉开成线，再从这条线展开成完整窗口；另一个方向是先竖后横。标准版 390ms（21:22 提速），慢速样板最长 880ms，看得见过程又不拖。关闭按原路逆向收回：窗收成线、线缩回点、遮罩淡出。

修订 2 · 危险确认弹窗入场特批「形状生长」。允许 clip-path 几何展开 + 一条 2px 生长线，总时长 380–900ms、分 2–3 段。退场同样特批：按原路逆向收回约 400ms，不做整层淡出。这是继 hazard 滚动条之后的第二个特例，只用于危险确认弹窗；普通弹窗 / 列表 / 按钮 / 卡片仍按 200ms 规范。仍然禁止：缩放变形、位移、旋转、回弹、错峰入场、整页转场。reduced-motion 下入场退场都直接切换。

项目里已先换上 F1（入场 390ms / 退场 400ms）；点 × / 取消 / ESC / 遮罩都能看到逆向收回。挑中别的说一声就切，改动只在 utilities.css。

01

展开组 · 五个样板

就绪
F1点 → 横线 → 上下展开当前项目
线 280ms（约 175ms 拉满）· 窗 240ms @150ms · 总 390ms ← 提速
怎么动：中心一个 2px 点，信号黄线向两侧拉开；线满的瞬间面板以这条线为轴向上下展开，内容随之露出。线在展开时淡出，不留痕。你说的第一种，21:22 已从 540ms 收紧到 390ms。
F2点 → 竖线 → 左右展开
竖线 280ms · 窗 240ms @150ms · 总 390ms
怎么动：先竖后横。中心点先纵向拉成一条竖线，面板再以竖线为轴向左右摊开。比 F1 更像"拉开一道帘子"，纵向感强一点。
F3慢速仪式版
线 700ms · 窗 460ms @420ms · 总 880ms
怎么动：F1 的节奏整体拉慢，线长得从容、窗展开得更稳。最有"设备自检 / 仪器启动"的味道。代价是每次确认都要等近 1 秒，天天用会嫌慢。
F4红线版
节奏同 F1（390ms）· 生长线改 --ef-danger
差异：生长线从信号黄换成危险红，和红边、红标题同一语义，整体更"警告"；黄线版则有"信号 / 启动"的中性仪器感。同一套动作，两种情绪。
F5纯几何 · 无亮线
单段 560ms · 0% 点 / 45% 横线 / 100% 窗
怎么动：不画独立生长线，全靠面板自己的 clip-path 三段关键帧：点 → 全宽细条 → 完整窗口。最干净、最克制，但那条"线"是面板背景色，存在感比亮线版弱。
✕仍然不做
scale(0.9→1) / spring 回弹 / 旋转 / 错峰
形状生长已经够有戏了。再叠缩放会把文字拉变形，回弹和旋转又会回到"乱飞"。窗口边框可以长，内容不能跟着变形——这是这轮所有样板的底线。

03

挑中之后怎么落地

项目里现在是 F1。换方案只动 utilities.css 一处，组件和页面逻辑不用碰。

样板改动
F1现状：入场 ef-grow-h + ef-reveal-v；退场 ef-collapse-v + ef-shrink-h + ef-overlay-out，生长线 --ef-action。组件用 rendered ref 延迟卸载，保证四条关闭路径都走退场
F2生长线改竖向（width 2px / scaleY），面板换 revealH
F3只把两个 animation 的时长/延迟按 700ms / 460ms@420ms 调大
F4生长线 background: var(--ef-danger)
F5删掉 .ef-hazard-grow 元素，面板换三段 revealGeom
验收口径：关掉动效，弹窗仍然一眼看出是危险区（红边 + 滚动条 + 红标题）。形状生长负责"出现得有分量"，不负责告诉用户这很危险。prefers-reduced-motion 下必须直接完整显示，不能把人卡在一条线上。

空片擦除读取 UID
危险操作 · 不可撤销 STC / CHIP ERASE
将向芯片发送擦除命令，从擦除应答取回 7 字节 UID（STC15/12/8 系列 BSL 只在擦除应答里附带 UID）。
  • 片内用户程序会被全部擦除，不可恢复——仅适用于未烧程序的空片
  • UID 区（程序区最后 7 字节）受硬件保护，擦不掉，擦除后 UID 依然有效
  • 读取后芯片停在 BSL，需重新上电才能运行程序
